# Project Templates Knowledge

Place standard assembly configurations, typical connection details, and reusable project patterns here.

## What Belongs Here
- Typical portal frame configurations (spans, heights, profiles)
- Standard base plate assemblies
- Handrail / staircase templates
- Bracing configurations
- Purlin/girt spacing tables

## File Naming Convention
- `portal_frame_standard.md` — Standard PEB portal frame dimensions
- `base_plate_templates.md` — Typical base plate configurations
- `handrail_details.md` — Standard handrail assembly specs
- `bracing_patterns.md` — X-bracing, K-bracing configurations
