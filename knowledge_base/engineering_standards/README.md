# Engineering Standards Knowledge

Place structural engineering codes, specifications, and reference tables here.

## What Belongs Here
- Eurocode (EN 1993, EN 1992, etc.)
- AISC Steel Construction Manual references
- IS 800 / IS 456 (Indian Standards)
- Bolt property tables (grades, capacities, torque values)
- Weld sizing guides
- Material property tables

## File Naming Convention
- `eurocode_bolts.md` — Bolt rules per EN 1993-1-8
- `aisc_connections.md` — AISC connection design rules
- `material_grades.md` — Steel/concrete grade properties
- `bolt_torque_tables.md` — Tightening torque values by grade
