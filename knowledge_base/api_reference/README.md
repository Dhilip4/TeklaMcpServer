# API Reference Knowledge

Place Tekla Open API documentation, class references, and code patterns here.

## What Belongs Here
- API class documentation (e.g., `Model`, `DrawingHandler`, `Operation`)
- Method signatures and parameter descriptions
- Known API quirks and workarounds
- Version-specific behavior (Tekla 2022 vs newer)

## File Naming Convention
- `api_model_objects.md` — Model-level API (beams, columns, plates)
- `api_drawing_objects.md` — Drawing-level API (marks, views, dimensions)
- `api_operations.md` — Operation class methods and behaviors
- `api_connections.md` — Component/connection API
