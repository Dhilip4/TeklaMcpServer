# Macros & Code Snippets

Place reusable C# code patterns, Tekla macros, and API tricks here.

## What Belongs Here
- Working macro examples (.cs format documented as .md)
- API workarounds and tricks
- Drawing automation patterns
- Bolt/weld/connection scripting patterns

## File Naming Convention
- `drawing_macro_execution.md` — How to trigger drawing macros via API
- `bolt_filtering_pattern.md` — Filtering bolts by name/size in drawings
- `model_holes_and_bolts_query.md` — Querying baseplate holes, tolerances, and bolt groups in model
- `batch_drawing_creation.md` — Creating drawings for multiple assemblies
- `numbering_macros.md` — Part/assembly numbering automation
